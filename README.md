# ITALCS3D
Codes for pre-processing atmospheric flow model data, running ITALCS3D, and plotting FTLE maps and tracers as they appear in "3D Lagrangian transport near the mesopause"

This repository contains the Integration and Tracing for Atmospheric Lagrangian Coherent Structures in 3D (ITALCS3D).  The code is written with Matlab functions and scripts. The Mapping Toolbox is required for some of the plots.  The repo includes a folder ITALCS3D/ which contains the functions needed for computing finite time Lyapunov exponent (FTLE) maps and tracer trajectories. It also includes a folder plotting_tools/ used for plotting the figures shown in the manuscript Datta-Barua, Pedatella, and Harvey, "3D Lagrangian transport near the mesopause," submitted 2026.

To compute FTLE maps, begin with main_waccm_italcs3d_script.m. Input and output folder paths need to be specified at the start of the script, and the ITALCS3D/ folder needs to be in the search path.

The input flow fields and output FTLE maps&tracers used in the paper are published at https://doi.org/10.5281/zenodo.23145610
Using the files there (or ones generated by running main_waccm_italcs3d_script.m), the following plotting tools can be used to generate figures as they appear in the paper:
Fig. 3:    plot_2d_vs_3d.m
Fig. 4:    plot_slices_of_3d.m
Fig. 5:    compare_two_days.m
Fig. 6-7:  compare_two_days_waccm_and_saber.m
Fig. 8:    plot_hovmoller.m

To run any of these, the user needs to modify the input and output paths at the top of the mfile, to correspond to the user's input/output paths.
